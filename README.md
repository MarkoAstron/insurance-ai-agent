AI Insurance Policy & Underwriting Assistant (MVP)
Прототип автономного ИИ-агента для автоматизации внутренних процессов страховой компании (на примере продуктов КCЖ). Проект демонстрирует интеграцию большой языковой модели (LLM) с корпоративными информационными системами через изолированный и безопасный слой API.

🚀 Бизнес-ценность решения
В страховом секторе (включая аннуитетное страхование и страхование от несчастных случаев) менеджеры тратят до 30% рабочего времени на рутинную проверку статусов договоров, верификацию данных клиентов по ИИН и ручной поиск причин приостановки выплат.

Данное решение автоматизирует обработку внутренних запросов:

Сокращение рутины: Агент самостоятельно агрегирует данные из разных систем (информация о клиенте + аудит полисов) за один шаг.

Снижение галлюцинаций: ИИ выполняет детерминированные действия (вызовы API), исключая выдумку фактов или сумм.

Безопасность контура: Модель полностью изолирована от базы данных. Доступ к PII (персональным данным) строго лимитирован и контролируется на уровне эндпоинтов REST API.

🛠 Технологический стек
Оркестрация ИИ: LangGraph / LangChain (реализация паттерна ReAct — Reasoning and Acting)

LLM Ядро: Llama 3.3 (70B) через высокопроизводительный API-инференс Groq

Корпоративный Бэкенд (Имитация): FastAPI (Python)

Валидация данных: Pydantic & Статический анализ типов Pylance

📋 Реализованный функционал (API & Tools)
GET /api/clients/{iin} (get_client_info) — извлечение профиля клиента (ФИО, категория, возраст).

GET /api/policies/{iin} (get_client_policies) — проверка страховых портфелей, статусов выплат (например, приостановка пенсионного аннуитета из-за истекшего удостоверения личности).

🔧 Инструкция по развертыванию
1. Клонирование и подготовка окружения
Bash
git clone https://github.com/your-username/insurance-ai-agent.git
cd insurance-ai-agent

# Создание и активация виртуального окружения
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
.\venv\Scripts\activate   # Для Windows
2. Установка зависимостей
Bash
pip install fastapi uvicorn langgraph langchain-groq langchain-core requests python-dotenv
3. Настройка переменных окружения
В файле main.py укажите ваш актуальный API-ключ от платформы Groq:

Python
os.environ["GROQ_API_KEY"] = "gsk_YourActualGroqApiKey..."
🖥 Запуск демонстрации
Решение спроектировано как клиент-серверное приложение, поэтому требует параллельного запуска двух процессов.

Шаг 1: Запуск имитации корпоративной системы (Бэкенд)
В первом терминале запустите сервер FastAPI:

Bash
uvicorn backend:app --reload
Интерактивная документация API (Swagger UI) будет доступна по адресу: http://127.0.0.1:8000/docs

Шаг 2: Запуск ИИ-агента
Во втором (параллельном) терминале запустите исполняемый скрипт агента:

Bash
python main.py
